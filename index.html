Project Title: Junk Web App ♻️

Tools & Technologies: Java, HTML, CSS

Description: Collaborated on a responsive web application designed to automate waste management tracking. The system updates the status of household waste collection in real-time, connecting residential homes with local trash collectors and corporate disposal agencies. Additionally, it implements a gamified point-awarding logic that incentivizes environmental sustainability by rewarding users who actively sort their waste into plastics, metals, and organic categories.

Key Takeaway: Learned how frontend presentation styles (HTML/CSS) seamlessly bridge with backend application logic (Java). Gained hands-on experience in collaborative version control, full-stack state configuration, and system debugging within a agile team structure.

Project Title: Parking Gate & Fee Calculator 🚗

Language / Environment: C Programming Language

Core Concepts Implemented: Conditional Decisions (if-else), Repetition Loops (while/for), Counters, Accumulators, and Financial Arithmetic.

Description: Built a command-line software terminal that processes incoming vehicles one at a time. The system prompts the operator to choose a vehicle type and input the total hours parked. It then automatically computes specific parking fees, tracks applied rate structures or penalties, and continuously updates a running tally of both the vehicle count and total daily revenue generated.

Key Takeaway: Mastered the practical usage of control structures to manage state data, update runtime counter balances, and manage data validation within real-world business constraints.
